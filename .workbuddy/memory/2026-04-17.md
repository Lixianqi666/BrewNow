# 2026-04-17 工作日志

## ER 图与数据库一致性修复

### 问题
ER 图中 admins 表与其他表无连接，之前错误删除了 r1/r2 关系。

### 解决方案
1. **数据库修改** (`brew-now.sql`)：
   - `users` 表添加 `admin_id` 字段 + 外键 `fk_users_admin`
   - `merchants` 表添加 `admin_id` 字段 + 外键 `fk_merchants_admin`
   - `products` 表添加 `admin_id` 字段 + 外键 `fk_products_admin`

2. **ER 图修改** (`ER 图-副本.drawio`)：
   - 恢复 r1: admins → users（管理，1:N）
   - 恢复 r2: admins → merchants（管理，1:N）
   - 新增 r8: admins → products（管理，1:N）
   - 关系位于 admins 下方，向上连接到 admins
