## 系统简介

沏刻茶叶电商平台是一个集商品展示、在线购买、商家管理、系统管理于一体的茶叶电商系统。平台包含三种用户角色：

- **消费者**：浏览商品、下单购买、管理订单
- **商家**：管理自己的商品和订单
- **管理员**：管理平台所有用户、商家、商品和订单

## 消费者使用指南

### 1. 注册与登录

**注册新账号**

1. 访问系统首页，点击右上角"登录/注册"
2. 切换到"注册"标签
3. 填写账号、用户名、密码等信息
4. 点击"注册"按钮完成注册

**登录系统**

1. 访问登录页面
2. 输入账号和密码
3. 点击"登录"按钮

### 2. 浏览商品

**首页浏览**

- 首页展示热门商品和智能推荐
- 可根据茶叶分类（绿茶、红茶、乌龙茶、白茶、花茶、普洱茶等）筛选
- 推荐系统会根据您的浏览和购买行为提供个性化推荐

**搜索商品**

- 在顶部搜索框输入关键词
- 支持按商品名称、品牌、产地搜索

**查看商品详情**

- 点击商品卡片进入详情页
- 查看商品图片、价格、描述、产地、口味特点等
- 查看其他用户的评价
- 查看相关推荐商品

### 3. 购物车

**添加商品到购物车**

- 在商品详情页点击"加入购物车"
- 选择购买数量

**管理购物车**

- 访问 `/cart` 页面查看购物车
- 修改商品数量
- 删除不需要的商品
- 勾选需要结算的商品

### 4. 下单与结算

**提交订单**

1. 在购物车页面点击"去结算"
2. 填写或选择收货地址
3. 选择支付方式（支付宝、微信、银行卡等）
4. 填写订单备注（可选）
5. 确认订单信息后提交

**订单支付**

- 在订单列表中找到待支付订单
- 点击"支付"完成付款

### 5. 订单管理

**查看订单**

- 访问 `/orders` 查看我的订单列表
- 可按订单状态筛选（待付款、已付款、已发货、已完成等）
- 点击订单进入详情页查看订单状态和物流信息

**订单操作**

- 待付款订单：可进行支付
- 已发货订单：可确认收货
- 已完成订单：可评价商品
- 任何状态订单：可申请取消（根据订单状态）

### 6. 商品评价

**评价商品**

1. 在订单详情中找到已完成的商品
2. 点击"评价"按钮
3. 选择评分（1-5星）
4. 填写评价内容
5. 提交评价

### 7. 收藏功能

**收藏商品**

- 在商品详情页点击"收藏"按钮
- 或将商品加入心愿单

**查看收藏**

- 访问 `/favorites` 查看我的收藏列表
- 可从收藏夹直接购买商品

### 8. 个人中心

**修改个人信息**

- 访问 `/profile` 进入个人中心
- 修改用户名、头像、性别等基本信息
- 绑定手机号和邮箱

**管理收货地址**

- 添加、编辑、删除收货地址
- 设置默认地址

## 商家使用指南

### 1. 商家入驻

1. 注册消费者账号
2. 联系管理员申请商家资质
3. 管理员审核通过后，账号升级为商家账号
4. 使用商家账号登录访问商家后台 `/merchant`

### 2. 商家后台

登录后进入商家后台，可查看：

- 销售数据统计
- 待处理订单数量
- 商品库存预警
- 经营概况

### 3. 商品管理

**添加商品**

1. 进入"商品管理"页面
2. 点击"添加商品"
3. 填写商品信息：
   - 商品名称
   - 品牌
   - 分类（绿茶、红茶等）
   - 产地
   - 价格
   - 库存数量
   - 商品描述
   - 上传商品图片
4. 提交审核（部分平台需要管理员审核）

**编辑商品**

- 在商品列表中点击"编辑"
- 修改商品信息
- 更新库存

**管理商品状态**

- 上架/下架商品
- 设置库存预警阈值

### 4. 订单管理

**查看订单**

- 进入"商家订单"页面
- 查看属于自己店铺的所有订单
- 按订单状态筛选

**处理订单**

- 待发货订单：点击"发货"并填写物流信息
- 已发货订单：查看物流状态
- 退款订单：处理退款申请

## 管理员使用指南

### 1. 管理员登录

使用管理员账号登录，自动跳转至管理后台 `/admin`

### 2. 管理后台概览

后台首页展示：

- 用户总数、商家总数、商品总数
- 订单统计与销售额
- 平台运营数据趋势

### 3. 用户管理

**查看用户列表**

- 查看所有消费者和商家用户
- 按角色、状态筛选
- 查看用户详情

**用户操作**

- 编辑用户信息
- 禁用/启用用户账号
- 删除违规用户（软删除）

### 4. 商家管理

**商家审核**

1. 进入"商家管理"页面
2. 查看待审核的商家申请
3. 查看商家资质信息
4. 选择"通过"或"拒绝"
5. 填写审核备注

**商家管理**

- 查看已审核商家列表
- 修改商家信息
- 暂停/恢复商家经营权限

### 5. 商品管理

**商品审核**

- 查看商家提交的新商品
- 审核商品信息是否合规
- 通过或拒绝商品上架

**商品管理**

- 查看所有平台商品
- 编辑商品信息
- 下架违规商品
- 设置推荐商品

### 6. 订单管理

**订单查看**

- 查看平台所有订单
- 按用户、商家、状态筛选
- 查看订单详情

**订单操作**

- 处理订单纠纷
- 强制取消订单
- 查看订单统计

### 7. 推荐统计

**推荐效果分析**

- 查看推荐算法的覆盖率、点击率等指标
- 分析推荐商品的销售转化
- 调整推荐算法参数

**数据统计**

- 用户行为统计
- 商品热度分析
- 推荐系统评估报告

## 常见问题

### Q1: 忘记密码怎么办？

A: 请联系管理员重置密码。

### Q2: 如何修改收货地址？

A: 在个人中心页面，进入"收货地址"管理，可添加、编辑或删除地址。

### Q3: 订单状态有哪些？

A: 
- 待付款 (PENDING)
- 已付款 (PAID)
- 已发货 (SHIPPED)
- 已送达 (DELIVERED)
- 已取消 (CANCELLED)
- 已退款 (REFUNDED)

### Q4: 商家如何申请入驻？

A: 先注册消费者账号，然后在个人中心或联系管理员申请商家资质，提交营业执照等信息，等待审核。

### Q5: 推荐系统是如何工作的？

A: 系统基于用户的浏览、收藏、加购、购买等行为数据，使用协同过滤算法计算商品推荐分数，为每个用户提供个性化的商品推荐。

### Q6: 支持哪些支付方式？

A: 平台支持支付宝、微信支付、银行卡支付、现金支付等方式。
